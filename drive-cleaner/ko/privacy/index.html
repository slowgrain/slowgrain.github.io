Slowgrain Cleaner for Google Drive 개인정보처리방침

1. 서비스와 운영자

Slowgrain Cleaner for Google Drive는 MORAON Studio(모라온 스튜디오)가 Slowgrain 브랜드로 제공하는 파일 관리 앱입니다. 이 정책은 앱이 Google 사용자 데이터를 어떻게 접근하고 사용하는지 설명합니다. Google Drive™는 Google LLC의 상표이며, Slowgrain Cleaner for Google Drive는 Google LLC와 제휴하거나 Google LLC의 보증을 받지 않았습니다.

사업자: 모라온 스튜디오 (MORAON Studio, 대한민국 개인사업자)
관할: 대한민국
개인정보 문의: slowgrain.dev@gmail.com
시행일: 2026-10-23

2. Google 사용자 데이터와 권한

앱은 https://www.googleapis.com/auth/drive.file 권한으로 사용자가 Google Picker에서 직접 고르거나 Google Drive의 '연결 앱으로 열기'로 보낸 파일만 처리합니다. 허용된 파일의 정보를 읽고, 사용자가 요청한 정리·복원을 위해 휴지통 이동이나 복원을 요청합니다. 앱은 파일을 영구 삭제하거나 다른 사용자와 공유하지 않습니다. 폴더를 선택해도 하위 파일·하위 폴더에 대한 접근은 생기지 않으며, 앱은 새 파일을 자동으로 찾거나 Drive 전체를 탐색하지 않습니다. 사용자가 켠 예약은 이미 허용하고 저장한 선택 파일 집합만 다시 검사합니다.

앱이 다루는 선택 파일 정보는 ID, 이름, MIME 유형, 허용된 범위에서 읽을 수 있는 상위 폴더 정보, 크기, 체크섬, 생성·수정 시각, 버전, 소유권·작업 가능 여부, 앱 전용 파일 메타데이터, 이미지·영상 해상도와 영상 길이, 미리보기와 분석 지문입니다. 이 정보는 중복·유사 파일 비교, 사용자가 요청한 정리·복원과 앱 기능에만 사용합니다.

Google OAuth 범위

  • drive.file: 직접 선택하거나 연결 앱으로 보낸 파일을 읽고, 사용자 요청에 따라 휴지통 이동·복원과 앱 전용 보호 표식 설정을 처리합니다.
  • drive.install: Google Drive의 '연결 앱으로 열기' 메뉴에 앱을 연결합니다.
  • drive.appdata: 앱 설정, 분석 지문, 작업 이력 같은 앱 전용 데이터를 사용자의 숨겨진 appDataFolder에 저장·조회·삭제합니다.
  • script.scriptapp: 사용자가 켠 예약 검사·정리의 Apps Script 트리거를 만들고 관리합니다.
  • script.external_request: Apps Script에서 선택한 파일에 대한 Google Drive API 요청과 앱 저장 파일 입출력을 수행하고, 사용자가 결제한 경우 Paddle API에서 거래를 확인합니다.

앱은 drive, drive.readonly, drive.metadata* 같은 전체 Drive 권한과 메일 발송 권한을 요청하지 않으며, 이메일을 보내지 않고 Gmail을 읽지 않습니다. 사용자는 Google 계정 보안 설정에서 권한을 철회할 수 있고, 철회하면 해당 권한이 필요한 기능은 작동하지 않습니다.

3. 앱 저장소와 처리 위치

  • Google Apps Script 사용자 속성: 계정의 라이선스, 예약 설정, 일부 분석 상태를 저장합니다.
  • 사용자의 숨겨진 Drive 앱 데이터 폴더: 선택 파일 목록(사용자가 켠 경우), 분석 지문, 정리·복원 작업 이력을 저장합니다. 일반 Drive 폴더에는 표시되지 않습니다.
  • 개별 파일의 앱 전용 메타데이터: 사용자가 '항상 보관'을 켜거나 끄면 해당 파일의 비공개 앱 메타데이터에 보호 표식을 저장·제거합니다. 파일 내용은 바꾸지 않습니다.
  • 브라우저: 선택한 사진·영상의 분석 대부분은 사용자의 브라우저에서 수행합니다. 재분석을 줄이기 위해 축소된 분석 지문을 브라우저 IndexedDB에 저장할 수 있고, 화면 설정은 브라우저 로컬 저장소에 저장합니다.
  • 선택형 로컬 분석 도우미: 사용자가 직접 설치하고 연결한 경우에만 선택 파일 ID와 버전·체크섬, 짧은 수명의 Google OAuth 토큰을 사용자 컴퓨터의 127.0.0.1에서 실행되는 도우미에 전달합니다. 도우미는 요청한 원본을 임시로 내려받아 분석한 뒤 작업이 끝나면 임시 원본을 지웁니다. 파생 지문과 재개 지점은 사용자의 로컬 캐시에 남을 수 있으며, 사용자는 도우미를 종료한 뒤 홈 폴더의 .cache/drive-cleaner-helper(Windows는 %USERPROFILE%\.cache\drive-cleaner-helper)를 직접 삭제할 수 있습니다.

4. 결제

Pro 결제는 판매 대행사(Merchant of Record)인 Paddle이 처리합니다. 앱의 구매 버튼은 https://slowgrain.app/drive-cleaner/buy/ 결제 페이지를 열고, 결제 정보는 Paddle이 직접 받습니다. 결제 페이지에는 구매를 사용자의 Google 계정에 연결하기 위한 무작위 확인값이 함께 전달되며, 이 값에는 이메일이나 파일 정보가 들어 있지 않습니다. 결제가 끝나면 앱은 Paddle API로 거래·구독 식별자, 가격, 확인값을 확인하고 앱 라이선스 상태를 사용자 속성에 저장합니다. Paddle이 수집하는 결제 정보의 항목·보관·환불은 Paddle의 정책과 결제 화면에 따릅니다.

5. 공유·판매·광고·분석

앱은 Google 사용자 데이터를 광고 목적으로 사용하거나 판매하지 않습니다. 파일 내용과 목록을 다른 사용자에게 공개하지 않습니다. 파일 정리·복원은 로그인 계정의 권한과 사용자가 선택한 동작을 따릅니다. 앱에는 제3자 광고나 제품 분석 SDK가 없습니다. Paddle은 사용자가 결제를 시작한 경우에만 결제 처리자로 관여합니다.

Google 사용자 데이터의 제공·이전 대상

  • Google LLC: 사용자가 허용한 파일의 내용과 정보는 Google Drive API를 통해 앱 화면과 Google Apps Script에서 요청한 기능을 처리하는 데 전달됩니다. 앱 설정·파일 목록·분석 지문·작업 이력은 사용자가 사용하는 Google 계정의 비공개 appDataFolder 등에 저장됩니다. Google은 Drive·Apps Script·저장 기능의 클라우드 제공자로서 이 데이터를 처리합니다.
  • 사용자 브라우저와 기기: 선택한 파일 정보는 중복·유사도 분석과 화면 표시를 위해 사용자의 브라우저로 전달됩니다. 사용자가 선택형 로컬 분석 도우미를 직접 연결한 경우에만, 분석 대상 파일의 내용과 파일 식별 정보, 짧은 수명의 Google OAuth 토큰이 같은 컴퓨터의 127.0.0.1에서 실행되는 도우미로 전달됩니다. 이 도우미는 원격 Slowgrain 서버가 아니며, 해당 파일을 MORAON Studio의 별도 서버로 전송하지 않습니다.
  • Paddle: 사용자가 결제를 시작하면 Paddle은 결제·거래·구독 처리에 필요한 정보를 받으며, 구매를 앱 계정에 연결하기 위한 무작위 확인값이 함께 전달될 수 있습니다. 앱은 거래 확인을 위해 거래 식별자와 가격 정보를 Paddle API에 요청합니다. Drive 파일 내용, 파일명·목록, Drive 메타데이터, 미디어 또는 분석 지문은 Paddle에 보내지 않습니다.
  • GitHub Pages: 제품·정책 사이트의 호스팅 제공자로서 방문자의 IP 주소 등 일반 웹 요청·보안 로그를 처리할 수 있습니다. 앱이 접근한 Drive 파일 정보는 GitHub Pages로 보내지 않습니다.

위 기능 제공에 필요한 경우를 제외하고 Google 사용자 데이터를 다른 제3자에게 제공하거나 이전하지 않습니다. 데이터를 판매하거나 광고·데이터 중개·범용 AI/ML 모델 학습에 사용하지 않습니다. 법률상 유효한 요청에 응하거나 서비스 보안·권리 보호가 필요한 경우에는 필요한 범위에서 정보를 공개할 수 있습니다. 지원을 위해 운영자가 파일 내용을 확인해야 하는 경우에는 법률상 요구되는 경우를 제외하고 사용자의 명시적 동의를 먼저 받습니다.

6. 보관 기간과 삭제

설정·지문·작업 이력은 사용자가 앱 데이터를 삭제할 때까지 보관하며 자동 만료 기간은 없습니다. 앱의 개인정보 및 앱 데이터 → 앱 데이터 삭제를 실행하면 앱 저장소 파일, 사용자 속성의 앱 데이터, 앱 예약 트리거, 현재 브라우저의 앱 분석 캐시와 환경설정을 삭제합니다. 이 동작은 Drive 원본 파일을 바꾸지 않습니다. Google 접근 권한을 철회해도 저장된 앱 데이터는 지워지지 않으므로, 가능하면 앱 데이터를 먼저 삭제한 뒤 권한을 철회해 주세요. 삭제 오류가 표시되면 slowgrain.dev@gmail.com으로 문의해 주세요.

앱의 데이터 삭제는 로컬 도우미의 별도 캐시, Google 계정·Apps Script·Google Cloud의 보안 또는 진단 로그, Paddle이 법률상 보관하는 거래 기록을 삭제하지 않습니다. 개별 파일의 '항상 보관' 표식은 사용자의 보관 선택을 지키기 위해 앱 데이터 삭제로 해제하지 않으며, 필요하면 검사 결과에서 직접 해제할 수 있습니다. Drive 휴지통의 파일은 사용자가 Google Drive에서 직접 복원하거나 영구 삭제합니다.

7. 보안과 정책

앱은 OAuth 토큰을 화면에 표시하거나 자체 데이터베이스에 보관하지 않습니다. 로컬 도우미에 전달한 토큰은 작업 중 메모리에서만 쓰이고 만료 후 폐기됩니다. Google Apps Script, Google Drive, Paddle 각 서비스의 보안 정책도 적용됩니다. 인터넷 전송이나 제3자 플랫폼을 완전히 위험 없이 만들 수 있다고 보장할 수는 없습니다.

Google API에서 받은 정보의 사용과 이전은 Google API Services User Data Policy와 Limited Use 요구사항을 준수합니다. Google 사용자 데이터는 범용 인공지능·머신러닝 모델 학습에 사용하지 않습니다. 보안 조사나 법률상 필요한 경우를 제외하고, 운영자가 지원을 위해 파일 내용을 보려면 사용자의 명시적 동의를 먼저 받습니다. 데이터 처리가 바뀌면 이 정책과 시행일을 갱신합니다.

9. 웹사이트와 서비스 제공자

공개 안내 페이지에는 광고, 분석 도구, 추적 픽셀, 외부 웹폰트, 회원가입 폼이 없습니다. 예외로 결제 페이지(/drive-cleaner/buy/)는 결제 화면을 열기 위해 Paddle.js를 불러옵니다. GitHub Pages가 사이트를 호스팅하며 IP 주소 같은 일반 요청·보안 로그를 처리할 수 있습니다. 앱 데이터는 위에 설명한 Google 서비스, 연결한 경우 로컬 도우미, 결제한 경우 Paddle이 처리하며, 각 제공자의 약관과 보호 조치에 따라 해외에서 처리될 수 있습니다. 지원 이메일은 문의 해결과 법률상 의무에 필요한 기간 보관하며, 삭제 요청은 개인정보 문의 주소로 받습니다.
