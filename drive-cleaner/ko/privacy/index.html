Slowgrain Cleaner for Google Drive™ 개인정보처리방침

1. 앱과 데이터 처리 주체

Slowgrain Cleaner for Google Drive™는 모라온 스튜디오가 Slowgrain 브랜드로 제공하는 파일 관리 앱입니다. 이 문서는 앱이 Google 사용자 데이터를 접근하고 사용하는 방식을 설명합니다. Google Drive™는 Google LLC의 상표입니다. Slowgrain Cleaner for Google Drive™는 Google LLC와 제휴하거나 Google의 승인을 받은 제품이 아닙니다.

2. Google 사용자 데이터와 권한

앱은 https://www.googleapis.com/auth/drive 권한으로 사용자가 로그인한 계정에서 접근 가능한 Drive 파일을 조회하고, 사용자가 실행한 정리·복원 작업을 위해 파일을 휴지통으로 이동하거나 복원할 수 있습니다. 앱은 파일을 영구 삭제하거나 다른 사용자와 공유하지 않습니다. 이 전체 Drive 권한은 전체 Drive·폴더 색인, 파일 목록 도구, 공유 상태 검사, 자동 정리, 작업 복원에 쓰이며, 사용자가 Picker에서 직접 선택한 파일 분석에도 사용됩니다. 로그인 사용자는 앱에서 검사 범위를 고릅니다. 기능을 쓰지 않는 동안 앱이 임의로 백그라운드 스캔을 시작하지 않습니다. 사용자가 설정한 Apps Script 트리거는 설정한 범위와 동작을 실행할 수 있습니다.

앱이 다루는 Drive 정보는 파일 ID, 이름, MIME 유형, 폴더 관계, 크기, 체크섬, 생성·수정 시각, 버전, 소유권·작업 가능 여부, 이미지·영상의 해상도와 영상 길이, 선택 기능을 위한 미리보기·분석 지문, 공유 권한 메타데이터 및 Drive 저장 공간 수치입니다. 파일 목록과 지문은 중복·유사 파일 비교, 사용자가 요청한 정리·복원 및 보고 기능에만 사용합니다.

Google OAuth 범위

  • drive: 사용자가 허용한 Drive 파일 목록과 메타데이터를 읽고, 사용자가 요청한 파일을 휴지통으로 이동·복원합니다. 전체 Drive 검사와 Picker 선택 파일 접근에도 사용합니다.
  • drive.appdata: 앱의 색인, 분석 지문, 보고서, 작업 이력 등 앱 전용 저장 데이터를 사용자의 숨겨진 appDataFolder에 저장·조회·삭제합니다.
  • script.scriptapp: 사용자가 켠 예약 검사·정리·보고서의 Apps Script 트리거를 만들고 관리합니다.
  • script.external_request: Apps Script에서 Google Drive API 미리보기와 앱 저장 파일 입출력을 요청하고, 사용자가 결제를 시작할 때 Paddle API 서버에 거래를 확인합니다.
  • script.send_mail: 사용자가 이메일 보고서를 별도로 켠 경우에만 계정 본인 주소로 요약 이메일을 보냅니다.

앱은 drive.file 범위를 별도로 요청하지 않습니다. 전체 Drive 기능 때문에 더 넓은 drive 범위가 필요합니다. 사용자는 Google 계정 보안 설정에서 권한을 철회할 수 있으며, 철회하면 해당 권한이 필요한 기능은 작동하지 않습니다.

3. 앱 저장소와 처리 위치

  • Google Apps Script 사용자 속성: 계정의 라이선스·예약 설정·일부 분석 상태·보고서 전달 상태를 저장합니다.
  • 사용자의 숨겨진 Drive 앱 데이터 폴더: 전체 Drive 파일 색인, 파생 분석 지문, 용량·공유 현황 스냅샷 및 정리·복원 작업 이력을 저장합니다. 앱은 이 정보를 일반 Drive 폴더에 표시하지 않습니다.
  • 브라우저: 선택한 미디어의 일부 분석은 사용자의 브라우저에서 수행합니다. 재분석을 줄이기 위해 축소 분석 지문을 브라우저 IndexedDB에 저장할 수 있습니다. 화면 설정은 브라우저 로컬 저장소에 저장합니다.
  • Apps Script 서버: 썸네일 미리보기 요청을 Google API에 전달하고 브라우저에 반환합니다. 앱은 이 기능을 자체 파일 보관소로 사용하지 않습니다.
  • 선택형 로컬 분석 도우미: 사용자가 직접 연결한 경우에만 선택 파일 ID와 버전·체크섬, 짧은 수명의 Google OAuth 토큰을 127.0.0.1의 사용자 컴퓨터에서 실행되는 도우미에 전달합니다. 도우미는 요청한 원본을 임시 다운로드해 FFmpeg 등으로 분석하고 원본 임시 파일을 작업 종료 후 제거합니다. 파생 지문과 재개 체크포인트는 사용자의 로컬 캐시에 남을 수 있습니다. 현재 앱에는 이 별도 캐시를 삭제하는 기능이 없으며, 사용자는 도우미를 종료한 뒤 사용자 홈 폴더의 .cache/drive-cleaner-helper를 직접 삭제할 수 있습니다. Windows에서는 %USERPROFILE%\.cache\drive-cleaner-helper입니다. 도우미는 별도 설치와 사용자의 연결 동작이 필요합니다.

4. 이메일과 결제

이메일 보고서는 사용자가 예약과 이메일 수신을 켠 경우, Drive 소유 계정 주소로 보내집니다. 이메일에는 스캔 범위의 파일 수, 중복 요약, 저장 공간 수치, 정리 결과 등 사용자가 선택한 보고서 정보가 포함될 수 있습니다. 앱은 Gmail 메일함을 읽지 않습니다.

Paddle 결제 연동이 활성화되면 Paddle은 결제·청구 정보를 직접 처리합니다. 앱은 거래·구독 식별자와 라이선스 상태를 확인하고 사용자 속성에 앱 라이선스를 저장합니다. Paddle에 제출하는 결제 정보의 항목·보관·환불 처리는 Paddle의 정책과 결제 화면에 따릅니다. 현재 구현 환경의 Paddle 상품·가격·키와 결제는 아직 설정·검증되지 않았으므로 결제 기능이 활성화되기 전까지 결제 정보를 받지 않습니다.

5. 공유·판매·광고·분석

앱은 Google 사용자 데이터를 광고 목적으로 사용하거나 판매하지 않습니다. 파일 내용·목록을 다른 사용자에게 공개하지 않습니다. 파일 정리·복원은 로그인 계정의 권한과 사용자가 선택한 동작을 따릅니다. 현재 앱에는 제3자 광고 또는 제품 분석 SDK가 없습니다. Paddle은 결제를 사용자가 직접 시작한 경우에만 결제 처리자로 관여합니다.

6. 보관 기간과 삭제

색인·지문·설정·작업 이력은 사용자가 앱 데이터를 삭제할 때까지 보관하며 현재 자동 만료 기간은 없습니다. 보고서에는 최대 최근 400개 스냅샷을 보관합니다. 사용자가 앱의 개인정보 및 앱 데이터 → 앱 데이터 삭제를 실행하면 앱 저장소 파일, 사용자 속성의 앱 데이터, 앱 예약 트리거 및 현재 브라우저의 앱 분석 캐시·환경설정을 삭제합니다. 이 동작은 Drive 원본 파일을 변경하지 않습니다. Google 접근 권한 철회만으로 저장된 앱 데이터가 삭제되지는 않으므로 가능한 경우 앱 데이터를 삭제한 뒤 권한을 철회해 주세요. 삭제 실패가 표시되면 slowgrain.dev@gmail.com로 문의해 주세요.

앱 화면의 데이터 삭제는 로컬 도우미의 별도 캐시, Google 계정·Apps Script·Google Cloud의 보안 또는 진단 로그, Paddle이 법률상 보관하는 거래 기록을 삭제하지 않습니다. 로컬 도우미 캐시는 도우미를 종료한 뒤 사용자가 컴퓨터에서 직접 삭제해야 합니다. 앱 실행에 필요한 Drive 권한은 Google 계정 설정에서 별도로 철회할 수 있습니다. Drive 휴지통 파일은 사용자가 직접 복원하거나 Google Drive에서 영구 삭제합니다.

7. 보안과 정책

앱은 OAuth 토큰을 로컬 도우미 연결에 필요한 경우 외에는 앱 UI에 노출하거나 자체 데이터베이스에 보관하지 않습니다. 도우미 토큰은 작업 중 메모리에서만 사용되고 만료 후 폐기됩니다. 접근 제어와 계정 보안은 Google Apps Script·Google Drive·Paddle의 각 서비스 정책도 적용받습니다. 인터넷을 통한 전송이나 제3자 플랫폼을 완전히 위험 없이 만들 수 있다고 보장할 수는 없습니다.

Google API에서 받은 정보의 사용 및 이전은 Google API Services User Data Policy와 Limited Use 요구사항을 준수합니다. Google 사용자 데이터는 범용 인공지능·머신러닝 모델 학습에 사용하지 않습니다. 보안 조사나 법률상 필요한 경우를 제외하고 운영자가 지원을 위해 파일 내용을 읽으려면 사용자의 명시적 동의를 먼저 받습니다. 데이터 처리 변경은 이 정책에 반영하고 공개 게시본의 시행일을 갱신합니다.
